# Claude Code Pointer

This is **LoogriGram for Android**, a fork of `DrKLO/Telegram`. Read
`LOOGRIGRAM.md` first — it covers the fork's state, the three-mode CI and its
measured costs, the traps that have each already cost real time, and what still
needs doing.

Note especially that there is no local JDK: **CI is the only compiler**, so use
`compile` mode and batch commits rather than compiling one at a time.

The parent directory's `.claude/CLAUDE.md` carries the lessons shared with the
desktop fork, which is worth reading if you are touching either.
